# 利用ガイド

## 対戦・3D表示

READMEのDocker起動後、ブラウザのnoVNCでPython画面を操作します。対戦設定とワークショップには相互に移動するボタンがあります。

青と赤は独立して機体、制御、戦略を選べます。まず既定のルールベース戦略で動作を確認してください。AI戦略は推論中も競技時計が進み、推論待ちが勝敗に影響します。

3Dプレビューは静止形状用です。ドラッグで回転、右ドラッグまたはShiftドラッグで平行移動、ホイールでズーム、Rで視点リセット、Vで装飾表示切替、Escで閉じます。Genesisの競技画面の操作とは別です。

## プロンプト生成の使い分け

|ボタン|範囲|
|---|---|
|新規機体を生成|独立した機体と制御を新規作成|
|機構を追加・再設計|関節数・形状を含めた機体と制御の変更|
|制御コードを生成・修正|形状を維持し、関節目標の計算コードを変更|
|機体のみ生成・編集|既存の形状・質量・摩擦などの属性調整|
|機体＋制御の変更案を生成|既存形状の属性と制御パラメータを調整|
|制御設定だけの変更案を生成|既存のゲイン・速度などの設定調整|

新しい関節を追加したい場合、下段のパラメータ調整では対応できません。未適用の案は3D確認できますが、診断・保存は適用後です。表示中の案と適用済み機体のスコアは対象が異なることがあります。

## 診断と自動改善

- 平地診断：直進・停止、旋回・移動、連続経路。
- 三段登坂：段差を垂直に進入し、段階ごとの目標を検証。
- 関節スモーク：ロードと短時間の動作確認。歩行や登坂の成功判定ではありません。

診断は切り分けのため直接観測を利用します。通常対戦のROS2通信とは別経路です。平地と段差は試験・上位段階が別ですが、機体と下位制御は共有します。

自動改善は上限回数を指定します。「機体・機構も変更する」がオンなら機体も対象です。モデルID・推論深さ・制限時間は画面で指定します。利用量を消費するため、まず少ない回数で確認してください。改善中も元の作成条件と各改訂を保持します。改善結果が悪化した場合の既存の復元判断と、表示用スコアは別の仕組みです。

制御性能スコアは達成40点、進捗30点、時間15点、安定性10点、駆動余裕5点。入力モデル・制御・調整設定が一致する検証だけを表示し、未評価と0点を区別します。高得点が、その後の改善しやすさを意味するわけではありません。

## データ

`/data/robot_workshop` に作成機体と診断ログ、`/data/evaluation_results` に対戦結果を保存します。ホストの個人ディレクトリは不要です。データはGitへ追加せず、必要な成果物だけ選んで持ち出してください。
