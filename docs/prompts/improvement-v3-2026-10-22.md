# 固定改善プロンプト v3

v2の達成済み動作保持・過去履歴との区別・一つの修正仮説という原則を維持し、
[段階的な診断構成](../2026-10-22-staged-diagnostics.md)を追加した。

症状→機構→指令と実動作→支持・足先軌道→フィードバック・制限→次の一手の順で確認する。
事実・仮説・未確認事項を分け、最初の未解決の問題に対応する。
必要なら同型ロボットの一次資料を読み、自由度・センサー・駆動・実行可能な制御形式の違いを明示する。
調査できていない資料を読んだと主張しない。参考方式がそのまま利用できるとは仮定しない。
アプリによるプロンプトの自動改訂ではなく、Codexで改訂した固定テンプレートである。
